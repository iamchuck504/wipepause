# WipePause website

Static marketing, support, and privacy website. No build step, dependencies, forms, or analytics.

## Vercel

Import `iamchuck504/wipepause`, use framework preset **Other**, repository root, and no build command. Serve the repository root. No environment variables are required.

The same HTML works on GitHub Pages. Keep `index.html` and `privacy.html` paths available for existing app links.

## Local preview

Run `python3 -m http.server 8765` from this directory.
