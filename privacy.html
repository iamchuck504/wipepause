Privacy Policy — WipePause

Last updated: 3 September 2026

The short version

The app temporarily suppresses input events during Cleaning Mode. It does not
record, store, or transmit keyboard or trackpad activity.

What WipePause collects

Nothing.

There is no account, no login, no sign-up, no analytics, no crash reporting, no

advertising identifier and no server. The app makes no network connections; it

holds no network entitlement, so it could not make one.

What happens to your keystrokes

While a session is running, keystrokes and trackpad events that macOS routes to

WipePause's window are discarded on arrival. They are not inspected, not

counted, not written anywhere and not passed to any other app.

The one exception is the Esc key. WipePause watches Esc — and only Esc — so

that pressing it five times quickly, or holding it, can end the session early.

To do that it keeps the *timestamps* of recent Esc presses in memory, for at

most a few seconds, and discards them when the session ends. The timestamps are

never written to disk.

WipePause never observes input directed at any other application and holds no

Input Monitoring permission. It asks for the Accessibility permission, and uses

it only while a session is running, only to stop keys (including function and

media keys), discarding those key presses without inspecting them.

What is stored on your Mac

Only your preferences — default duration, which devices to lock, countdown

length, sounds, unlock method, appearance — in the app's own sandbox container.

They never leave your Mac. Reset to Defaults in Preferences clears them, and

deleting the app removes them.

Permissions

WipePause asks for one system permission: Accessibility. It is requested on

first launch (and again on later launches until granted), because macOS handles

brightness, volume, media and similar keys before any app sees them, and the

lock cannot stop them without it. Its only entitlement is the App Sandbox.

With the permission granted, WipePause drops the locked device's events

(keys, media keys or trackpad) only while a cleaning

session is running, and looks at exactly one thing: whether a key is Esc, so

the emergency unlock keeps working. It still reads, records and transmits

nothing. Without the permission the app still works, but function and media

keys stay active during a session; you can remove WipePause from Accessibility

in System Settings at any time.

Children

WipePause collects no data from anyone, of any age.

Changes

Any change to this policy will be published with the app update it belongs to,

with the date above updated.
